- Achievements and skills

## Deploy on Vercel

This is a static HTML/CSS/JS website.

Vercel settings:

- Framework Preset: Other
- Build Command: leave empty
- Output Directory: leave empty
- Install Command: leave empty

## Update existing GitHub repo

Do not copy the `.git` folder into this project. Replace the files inside your existing cloned repository, then run:

```bash
git status
git add .
git commit -m "Update portfolio projects section"
git push
```

If the repo is already connected to Vercel, the push will trigger a new deployment.
